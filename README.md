## Цель работы

Создание Spring-приложения с несколькими связанными таблицами с использованием Java Persistent API для автоматизации учета военнослужащих.

## Архитектура проекта

* **Стек:** Spring Boot 3, Maven, Java 21, Thymeleaf
* **СУБД:** H2 (In-Memory Database)
* **Основные слои:**
* **Controller:** `ServicemanController` (обработка HTTP-запросов, передача данных в модель и маршрутизация).
* **Repository:** `ServicemanRepository`, `RankRepository`, `AddressRepository` (интерфейсы, наследующие `CrudRepository`, для выполнения CRUD-операций и кастомных методов для получения данных).
* **Model (Entity):** `Serviceman`, `Rank`, `Address` (сущности, отображающие таблицы БД и связи между ними).
* **View:** HTML-шаблоны Thymeleaf (представление данных пользователю).
* **Ключевые аннотации:**
* *Для настройки БД и сущностей:* `@Entity` (объявление сущности БД), `@Table` (привязка к таблице), `@Id` (первичный ключ), `@GeneratedValue` (стратегия генерации ключа).
* *Для настройки связей:* `@ManyToOne` (связь «много к одному»), `@OneToMany` (связь «один ко многим»), `@JoinColumn` (создание внешнего ключа в таблице).
* *Для контроллера:* `@Controller`, `@GetMapping`, `@PostMapping`, `@PathVariable`, `@ModelAttribute`.

## Алгоритм работы

1. **Проектирование базы данных:** Выделение трех связанных таблиц на основе предметной области: главной таблицы `servicemen` и таблиц-справочников `ranks` (звания) и `addresses` (адреса).
2. **Инициализация данных:** Автоматическое создание таблиц и заполнение их тестовыми записями при запуске приложения с помощью настроенных SQL-скриптов `schema.sql` и `data.sql`.
3. **Настройка связей JPA:** Настройка двунаправленных связей между сущностями. Для класса `Serviceman` настроены обязательные связи `@ManyToOne` со званием и адресом, а в классах `Rank` и `Address` настроена обратная связь `@OneToMany`.
4. **Реализация поиска:** Создание кастомных методов в `ServicemanRepository` для фильтрации и отбора данных по трем комбинациям (поиск по части фамилии, по названию звания и по городу проживания) с игнорированием регистра.
5. **Связывание с интерфейсом:** Реализация методов в контроллере для передачи списков всех военнослужащих, званий и адресов на HTML-страницы. Внедрение выпадающих списков (тегов `<select>`) в формы добавления и редактирования для корректного сохранения связанных объектов.
